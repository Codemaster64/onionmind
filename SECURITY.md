# Security Policy

## Supported versions

Onionmind is a small, fast-moving project. Security fixes are applied to the
current `main` branch and the newest published artifacts.

| Version | Supported |
| --- | --- |
| `main` / `desktop-latest` | Yes |
| Latest tagged Android and Matchstick releases | Yes |
| Older tags and copied installer scripts | No |

Before reporting, reproduce the issue against the current source or latest
artifact when it is safe to do so.

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private [Report a vulnerability](https://github.com/Codemaster64/onionmind/security/advisories/new)
form instead.

Include the affected version or commit, platform, impact, reproduction steps,
and any suggested mitigation. Remove prompts, source code, usernames, network
addresses, and other sensitive data from logs before attaching them.

The maintainer will coordinate validation, a fix, and disclosure through the
private advisory. Please allow time for a corrected artifact to be published
before disclosing the issue publicly.
